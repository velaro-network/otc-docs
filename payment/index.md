# Velaro Payment API

Pay foreign suppliers from Brazil: the customer pays **BRL by Pix**, the payee
receives **USD** in their bank account abroad.

The API lets you onboard a business customer (KYB), register the payees it
pays, lock a price, create the payment order and follow it to settlement —
by polling or through signed webhooks.

[!ref Get started](overview.md)
[!ref API Reference](api/index.md)

:::card
**One price, locked** — a firm quote fixes the BRL the customer pays for the amount the payee receives.
:::

:::card
**Simple & authenticated** — a REST API and one API key. JSON in, JSON out.
:::

:::card
**Status you can follow** — every order reports one forward-only status, pushed to you by webhook.
:::

:::card
**BRL → USD** — Pix collection in Brazil, USD payout to the payee's bank account.
:::
